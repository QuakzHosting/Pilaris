Frequently asked questions

Everything you need to know about deploying and managing game servers on Pilaris.

Can I upload my existing world or modpack?

Yes. You can upload existing world folders, plugin configs, or custom server jars using the built-in Web File Manager or via SFTP.

How does DDoS protection work for game traffic?

Every node includes always-on L3/L4/L7 mitigation tuned for UDP game protocols and query ports, filtering malicious floods without adding noticeable latency for players.

Can I switch games or upgrade RAM later?

Yes. You can scale your server's RAM, CPU, and storage from the control panel as your player count or modpack grows, without losing your world data.

Are automated backups included?

Yes. You can create manual snapshots before risky updates or schedule automated backups in the Backups tab and restore any point in one click.
